## 📚 오늘 배운 내용

오늘은 반복문(for, while)에 대해 학습했다.

반복문은 같은 코드를 여러 번 실행하거나,
규칙적인 패턴을 처리할 때 사용하는 문법이다.

---

# 1. for문

시퀀스 자료형(리스트, 문자열 등)의 원소를 하나씩 꺼내 반복 실행할 수 있다.

기본 구조:

```for 변수 in 시퀀스:
    실행할 코드

예시:

sum = 0

for i in [1, 3, 5]:
    sum = sum + i

print(sum)

출력 결과:

9```

---

## ✔ 문자열 반복 처리

문자열 안 특정 문자 개수 세기

```count = 0

for i in mix:
    if i == "쌀":
        count = count + 1

print(count)```

- 문자열도 반복 가능
- 조건문과 함께 사용 가능

---

## ✔ 리스트 조건 검색

대한민국 공항만 추출하기

```korea_airport = []

for airport in airports:
    if "대한민국" in airport:
        korea_airport.append(airport)

print(korea_airport)```

배운 점:
- in 연산자로 문자열 포함 여부 확인 가능
- append()로 원하는 데이터만 저장 가능

---

# 2. for-range문

range()를 사용하면 숫자 범위를 반복할 수 있다.

기본 구조:

```for 변수 in range(시작값, 끝값):
    실행할 코드```

---

## ✔ range 특징

```range(5)
# 0 ~ 4

range(1, 5)
# 1 ~ 4

list(range(5))
# [0, 1, 2, 3, 4]```

---

## ✔ 구구단 출력

```for i in range(1, 20):
    print("19 x", i, "=", 19 * i)```

---

## ✔ len()과 함께 사용

```str_list = ["H", "e", "l", "l", "o"]

for idx in range(len(str_list)):
    print(str_list[idx])```

배운 점:
- len()으로 길이 확인 가능
- 인덱스를 이용한 반복 가능

---

# 3. while문

조건이 True인 동안 반복 실행된다.

```기본 구조:

while 조건:
    실행할 코드```

---

## ✔ while 기본 예제

```i = 5

while i > 0:
    print(i)
    i = i - 1

출력 결과:

5
4
3
2
1```

---

## ✔ 무한 루프

```i = 1

while i > 0:
    print(i)```

조건이 계속 True이면 종료되지 않는다.

---

## ✔ break로 반복 종료

```i = 1

while i > 0:
    print(i)

    if i >= 5:
        break

    i = i + 1

print("종료")```

배운 점:
- break를 사용하면 반복문 탈출 가능

---

# 4. 실습 내용

## ✔ 수감 연수 출력

```i = 1

while i < 11:
    print(i, "년째 수감중입니다.")
    i = i + 1

print("감옥에서 석방되었습니다!")```

---

## ✔ 쇼핑 리스트 만들기

```shopping_list = []

while True:
    product = input()

    if product == "구매":
        break

    shopping_list.append(product)

print(shopping_list)```

배운 점:
- while True는 무한 반복
- break로 종료 가능
- 사용자 입력을 계속 받을 수 있음

---

# 💡 오늘 새롭게 알게 된 점

- 반복문은 같은 작업을 자동화할 수 있다.
- for문은 시퀀스 자료형 반복에 적합하다.
- range()를 이용하면 숫자 범위를 쉽게 반복할 수 있다.
- while문은 조건 기반 반복이다.
- break를 이용해 반복문을 종료할 수 있다.

---

# 🧠 어려웠던 부분

- while문의 종료 조건을 제대로 설정하지 않으면 무한 루프가 발생한다.
- for문과 while문의 차이를 익히는 중이다.
- range()의 끝 숫자는 포함되지 않는 점이 헷갈렸다.
