## 📚 오늘 배운 내용

### 1. 입력(input)과 자료형 변환
- input()은 기본적으로 문자열(str)로 값을 받는다.
- 숫자로 사용하려면 int(), float()로 변환해야 한다.
- type()을 통해 현재 자료형을 확인할 수 있다.

📌 예시:
```python
var = int(input())
print(type(var))
```

### 2. 자료형 변환 함수
- int() : 정수형
- str() : 문자열
- float() : 실수형
- list(), tuple(), set(), dict(), bool() 등 다양한 변환 가능

### 3. 논리형(Boolean)과 비교 연산자
- True / False 값으로 이루어진 자료형
- 비교 연산자:
>, <, >=, <=, ==, !=

```📌 예:

3 > 2  # True
3 == 3 # True
True는 1, False는 0처럼 계산에 사용 가능
``` 

### 4. 논리 연산자
- and : 모두 True일 때 True
- or : 하나라도 True면 True
- not : 반대값

```📌 예:

True and False  # False
not True        # False
```

### 5. 조건문 (if / elif / else)
- 조건에 따라 다른 코드 실행
- 들여쓰기로 코드 블록 구분

``` 📌 기본 구조:

if 조건:
    실행문
elif 조건:
    실행문
else:
    실행문
```

### 🧪 실습 내용
```
✔ 홀수 / 짝수 판별
if num % 2 == 1:
    print("홀수")
else:
    print("짝수")
✔ Up & Down 게임
if answer < submit:
    print("정답보다 더 큰 수를 입력했습니다.")
elif answer > submit:
    print("정답보다 더 작은 수를 입력했습니다.")
else:
    print("정답!")
```

## 💡 오늘 느낀 점
- input → int 변환이 생각보다 중요함
- 조건문 구조가 프로그래밍 핵심이라는 느낌
- 논리 연산(and/or/not)이 처음엔 헷갈림
