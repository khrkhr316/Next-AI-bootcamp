## 📚 오늘 배운 내용

### 1. 리스트(List) 활용

리스트에 데이터를 추가, 삽입, 삭제, 정렬하는 방법을 배웠다.

### ✔ append()
리스트 마지막에 원소 추가

```
a = []
a.append(1)

print(a)
# [1]
```

### ✔ insert()

특정 위치(index)에 원소 삽입

```
c = [1, 2, 3]

c.insert(1, "a")

print(c)
# [1, 'a', 2, 3]
```

### ✔ remove()

리스트에서 처음 발견되는 특정 값 삭제

```
my_list = [1, 2, 3, 2]

my_list.remove(2)

print(my_list)
# [1, 3, 2]
```

### ✔ sort()

리스트 정렬

```
numbers = [3, 1, 4, 2]

numbers.sort()

print(numbers)
# [1, 2, 3, 4]
```

- 숫자는 오름차순 정렬
- 문자열은 사전순 정렬 가능

### 2. 시퀀스 자료형

문자열(str), 리스트(list)처럼 순서가 존재하는 자료형을 시퀀스 자료형이라고 한다.

특징
- 인덱싱 가능
- 슬라이싱 가능
- 길이(len) 확인 가능
- 반복(*) 가능
- 포함 여부(in) 확인 가능

### ✔ 인덱싱 / 슬라이싱
```
a = "Hello"

print(a[0])   # H
print(a[-1])  # o
print(a[1:4]) # ell
```

### ✔ in 연산자
```
print("H" in "Hello")
# True
✔ len()
print(len("Hello"))
# 5
```

### ✔ 문자열 / 리스트 반복

```
print("Hi" * 3)
# HiHiHi
```

### 3. 지하철 역 이름 실습

### ✔ 특정 데이터 찾기
``` 
if '*' in station: 
```
문자열 안에 특정 문자가 포함되어 있는지 확인 가능

### ✔ 리스트에 결과 저장
```
error_line3_list.append(station)
```
조건에 맞는 데이터를 리스트에 추가 가능

### 4. 반복문(for문) 활용

리스트 안의 데이터를 하나씩 꺼내 반복 처리 가능

```
for station in line4:
    print(station)
```

### 💡 오늘 새롭게 알게 된 점

- 리스트는 데이터 추가/삭제/정렬이 가능하다.
- 문자열과 리스트는 둘 다 시퀀스 자료형이다.
- in 연산자를 이용하면 특정 값 포함 여부를 쉽게 확인할 수 있다.
- 반복문과 조건문을 같이 사용하면 원하는 데이터만 추출할 수 있다.
